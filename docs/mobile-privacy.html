声音与麦克风

只有你点击“开始监听”并允许麦克风后，邻证才会在本机分析声音电平。测量期间会生成临时音频缓存；正常停止后删除。异常退出留下的已登记缓存会在下次启动时清理。手机首版不保留可回放录音，不使用摄像头、定位、通讯录或照片。

事件与本机存储

应用保存事件时间、持续时长、峰值、平均电平、采样数量和校准设置，以便你回看声音变化。数据保存在应用的本机存储中；应用没有账号、广告、分析统计或云同步，不向开发者服务器上传声音或事件。系统备份和迁移由你的设备设置控制。

你可以控制的数据

你可以随时停止监听，在系统设置中撤销麦克风权限，并在本页删除本机事件记录。删除记录不会清除你的阈值与校准设置。设备系统备份中的副本由系统备份设置管理。

监听范围与校准

首版只在前台监听，进入后台或锁屏会停止；监听期间会保持屏幕开启。未校准显示 dBFS 麦克风电平，对照声级计校准后显示参考分贝。读数受设备、摆放和自动增益影响，用于个人记录与比较。

支持与政策更新

使用下方支持入口可以向开发者反馈问题。只需描述设备型号、系统版本和复现步骤；请勿提交含私人声音或其他敏感内容的文件。支持网站由 GitHub 提供，访问该网站时适用它的隐私政策。本政策变更会同步更新日期与公开页面。

NoiseLog Mobile Privacy Policy

Microphone access begins only when you start monitoring and grant permission. Sound is analyzed on the device. Temporary measurement audio is deleted after a normal stop; a registered cache file left by an interrupted session is cleaned up on the next launch. Version 1.0 stores event timestamps, duration, peak and average levels, sample count, and calibration locally. It retains no playable recordings. No camera, location, contacts, or photo access is used.

No account, ads, analytics, or developer cloud upload is used. You can stop monitoring, revoke microphone permission in system settings, and delete all local event records in Privacy & Settings. Device backups and their copies are controlled by your operating system settings. Monitoring stops in the background or when locked. Uncalibrated readings are dBFS; calibrated readings are reference levels, affected by hardware and placement.

For support, use the contact link above. Submit device model, OS version, and reproduction steps without private audio. GitHub handles support-site visits under its own privacy policy.
