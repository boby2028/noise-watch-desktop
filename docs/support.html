邻证 NoiseLog 支持

邻证支持 macOS 12 或更高版本，以及 Windows 10/11 x64。

常见检查

摄像头或麦克风不可用时，请在系统“隐私与安全”设置中允许邻证访问对应设备，然后重新启动应用。

夜间长时间运行时请接通电源、保持电脑开盖，并预留至少 10 GB 磁盘空间。触发前预录保存在内存中，只有触发片段写入磁盘。

校准时请将应用切换到快档，使用稳定声源，让物理分贝仪读数稳定后再输入；应用会采样 5 秒并排除瞬时波动。

提交问题

请前往 GitHub Issues，附上系统版本、应用版本、麦克风/摄像头型号和复现步骤。请勿上传包含他人声音、面部或住址的证据文件。

For support in English, open a ticket in GitHub Issues with your OS version, app version, device model, and reproduction steps. Do not attach private evidence files.
